# Historical development material, 30 October 2026

This directory is a historical archive, not part of the current V93 submission.

`development_history_with_v93_context.pdf` preserves the earlier 12-page draft,
including the old pooled-source controller comparisons, its ten-seed validation,
and the V91/V98 development results. The embedded V93 comparison supplies the
context in which that historical draft was written. All numerical data are
unchanged.

`latex_source/` contains the corresponding LaTeX text, bibliography, classes,
rendered figures, and compact historical CSV evidence. Compile `main.tex` inside
that directory. The rendered V93 figures are retained for rebuilding this
historical document; no models, native trajectories, or new MP execution
records are copied here. Simulation execution still requires the original
project and server archive.
