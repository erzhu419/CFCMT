# TSC V144 Multicity Source-Compatibility Inventory Protocol

## Purpose

V143 rejected a fixed uniform ensemble because it did not reliably improve
target-only CFCMT, despite improving pooled H2O+ in all seven cities. V144 asks
the narrower development question required before another method is built:
does source identity create enough reproducible cross-city headroom to justify
a target-label-free compatibility gate?

V144 is not a gate and has no confirmatory claim. It records the complete 42
ordered source-to-target effects over the seven admitted city groups.

## Information boundary

For each complete-city target, V144 reuses the frozen B25 adaptation split and
six one-source CFCMT components from V143. It reports every one-source policy
against target-only and a source-specific whole-action-group permutation
placebo. The target city remains excluded from every source fit.

Each city also receives a scenario-equal covariate signature containing only
current-state/action features and static context. Priors, next-state targets,
counterfactual costs and target evaluation labels are excluded from this
signature. These signatures may later instantiate a gate but cannot determine
the V144 oracle source identities.

## Headroom admission

The descriptive best source must improve target-only by at least 0.0005 in at
least five of seven target cities. This threshold only decides whether source
compatibility development is worthwhile. It does not authorize reporting the
oracle, selecting sources on target outcomes or running untouched-city
confirmation.

If admitted, the successor must train source compatibility with the evaluated
target city completely absent from meta-gate labels, including rows where that
city would otherwise act as a source. If rejected, source selection development
closes under the current mechanism representation.
