# 纯目标递推模型与独立校准方案

固定一个物理packet核＋联合广义线性模型（GLM）：38项固定物理量输入，190个系数，预测速度残差、启动、让行和换道。车辆参数直接作为已知输入；转向/END意图持续保留，边界受阻需求留在队列。成本由逐秒停车数积分，不拟合成本头。

静态输入核对发现6295辆车中有77辆在仍有后续连接的内部道路结束行程，因此加入END意图；个体路线不进入预测。因果初始化、持续意图、阻塞队列、身份账及速度约束与数值校准原型的9项合成测试通过。**完整交通递推核、训练器和采集器尚未实现，本轮0仿真、0真实数据拟合。**

拟定后续预算：4个训练种子＋2个独立校准种子，每个1800秒PP单轨，共6次启动、3模拟小时；1次联合优化＋4项训练历史分布估计，共5项拟合操作。校准只用两种子的t600/t1200，共4个450秒窗口、每窗8个模型场景，不另启原生分支。先导数据全部排除。

下一步先实现完整递推核并验收纯合成小网络，再按[协议](protocol.json)决定是否启动上述预算。门槛预先固定；失败不在同一校准集调参重跑。通过只支持技术校准，动作排序和来源增量仍需后续独立检验。
