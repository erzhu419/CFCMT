# 904配对样本的精确概率比较

全部62对、124个状态完成。两种参数下，真实换道及配对保持样本均有非零概率。局部随机车辆数为1至3，精确枚举使用2444次物理求解，低于原拟采用的256粒子方案的31744次。[结果](result.json)

| 方向 | 对数 | 真实换道平均NLL，原始→拟合 | 保持样本实际标签NLL，原始→拟合 | 拟合后给真实换道更高方向概率 |
|---|---:|---:|---:|---:|
| 左 | 32 | 1.132→8.649 | 0.480→0.005 | 17／32 |
| 右 | 30 | 1.940→3.315 | 0.300→0.209 | 15／30 |

原始参数在32对左样本中全部给出相同方向概率，右侧为1胜、27平、2负。拟合后的成对区分度为左53.1%、右50.0%，六个5分钟段的方向也有波动。全部32个左换道正例的概率下降。右侧18个正例提高、12个下降，平均NLL仍变差。

四格分解定位了本车类别打分的影响。左侧只替换本车类别概率，正例NLL就达到8.649，与完整拟合一致，仅替换其他分支权重仍为1.132。右侧相应为3.324、1.930，完整拟合为3.315。这批样本中，保持标签的损失降低，真实换道标签的损失升高，成对条件区分较弱。

124例的几何集合、原始配对条件和预算均核对通过。最大归一化误差8.88e−16，两个端点与原缓存边际概率的NLL误差为0。运行于jtl110gpu2，耗时502秒，实际1075次特征计算、8916个叶分支。新增原生仿真、拟合和优化调用均为0，完整缓存留服务器，本地取25.8 KB汇总。[执行](execution.json)

四条轨迹均进入过先验，数据有早期模型开发用途。结论限于当前系数、904和该匹配面板，匹配的类别比例用于方向诊断。自然发生率下的概率校准需要恢复原抽样权重。
