# 杭州源网通过静态检查和两次整小时 PP 复验

任务 `t213856` 在 `node006` 按[冻结方案](../tsc_jinan_left_geometry_20261107/next_plan.json)编译了一个独立候选。原始 CityFlow 在 16 个路口均同时放行对应的对向左转。32 对源车道曲线间距均为 8.55 米。64 条适配后的曲线在实际编译网络中端点误差为 0，各对间距均为 7.99 米，按车道宽度计算的净距为 4.79 米。[源几何核对](source_gate.json) · [候选构建](build.json)

| 全网检查 | 旧杭州源网 | 修复候选 |
|---|---:|---:|
| 全部冲突车道都正确让行的右转–直行组合 | 32/64 | 64/64 |
| 右转正确让左转的冲突车道对 | 0/576 | 576/576 |
| 标为冲突且同时获保护绿的对向左转车道对 | 32 | 0 |
| 未解决的独立共绿车道冲突情境 | 896 | 0 |

原需求、原稳定相位及逐连接灯色、编辑范围外的转向曲线均通过检查。普查仅使用从旧网逐一重绑的 32 个右转–直行组合。[静态验收](static_admission.json)

| 原开发种子 | PP 完成时间 | 碰撞 / 传送 | 六种车数组合中符合 4/0 秒放行且前两辆直行车静止的观测条数 | 已选起点 |
|---|---:|---:|---:|---:|
| 32061101 | 3,600 秒 | 0 / 0 | 89 | 6/6 |
| 32061102 | 3,600 秒 | 0 / 0 | 83 | 6/6 |

观测条数按每 10 秒、每个登记转向组合计，同一连续排队可被多次观测。12 个选定起点均保存了动作前状态，并核对了两辆静止直行车的身份。右转 3 辆、直行 2 辆在两种子分别只有 3、1 条合格观测。完整轨迹留在服务器。本轮未运行预测分支或策略比较。[普查与名册](census.json) · [运行回执](execution.json)
