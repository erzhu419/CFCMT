**济南负迁移集中在“直行、过去10秒推进速度不超过限速一半、历史速度ETA超过10秒”的格子。** 进入时下游有排队的格子，来源只有3条快照，本地105–176条。来源3/3都在10秒内到达，但物理锚为0、伪计数20，使来源后验降为3/23=13.04%；与本地平均66.27%等权混合后仅39.66%，从“计入到达”翻成“不计入”。开发记录实际到达比例为67.64%。此处源经验本身支持到达，稀疏来源头携带的强物理先验却获得了50%的融合权重。

进入时没有排队的同类格子，来源14条、本地58–99条，也受同一机制影响。其融合概率在三个适配块分别为44.38%、50.63%、48.07%，块0和2跨到0.5以下，块1没有翻转。[三块明细](sparse_context_blocks.json) 源/目标累计概率差的精确分解显示，这两格均以先验占比差异为主。

**锁相与可换相的误差应分开解释。** 济南可换相部分8,595个路段时刻，总绝对计数误差1748→1705，24处改善、0处退化；全部219个变差路段时刻均在锁相部分。对原六种子等权平均误差的贡献，可换相为−0.0009664、锁相为+0.0022395，合计仍为+0.0012731。因此事后分组不改变原门槛失败。[精确分组](lock_loss.json)

**证据范围。** 所有结果只解释既有规则轨迹中的固定预测与评分，没有测量换相后的等待收益。逐车判断、路段绝对计数误差和等种子平均误差分别统计；累计概率差的线性分解不能换算成误差收益百分比。来源支持计数是快照数，不能视为独立车辆数。杭州正向预测增益同样受先验占比变化影响，尚不能全部归因于可迁移车流规律。
