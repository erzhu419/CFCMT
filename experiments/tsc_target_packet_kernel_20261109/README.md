# 逐车递推核：工程实现与合成验收完成

已接通逐秒纵移、完整内部路径、有向让行与冲突预约、换道及车尾占用、持续转向/END、边界待插入队列，以及读取预测车道状态的原PP和执行器。停车成本只积分更新后的状态。默认系数明确标记为未训练；不同候选动作共享外生需求和逐车潜在随机量。

相关39项测试通过（新增30项＋前期原型9项），包括持续450秒插入/通行/退出、两次换道、切相清空和身份/成本闭合。修复了停止线附近空车道被误当作前车、遗漏有向让行、换道先抽再拒、接收阻塞后预约未更新，以及动作改变后续需求随机流的问题。

jtl110gpu2上对真实济南静态图的432条内部路径核对通过；618车道、700个人工车辆的10步运行亦通过，700−220=480的身份账闭合。只读取静态图和执行器静态配置，未加载实测车辆轨迹。本轮新增原生启动0、真实拟合0，密集测量以来累计原生启动仍为9。

**下一步：** 接上固定的训练似然、单轨采集器和独立校准评估器，再进入已列出的4训练＋2校准、各1800秒预算。先导8臂继续排除于模型数据；当前没有启动这些轨迹。

**局限。** 当前只完成工程与合成验收，尚未验证真实预测、动作排序或来源收益。规模检查约0.324秒/模型秒，尚不适合10秒内完成多动作、多场景450秒搜索；实时计算还需优化。该速度只来自10步人工场景，不是整段450秒计时。
