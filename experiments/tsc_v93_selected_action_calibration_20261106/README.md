# V93 最终选中动作误差标定

本轮以冻结 V93 为比较基准，历史七策略结果和新种子四策略验证分别保留。后续方法和论文主版本按[当前研究方向](../RESEARCH_DIRECTION_20261106.md)重新选择，V93 可以简化或替换；本轮未修改部署控制器。

固定 Atlanta 权重 1、α=0.9、β=0.5 和原预测模型族。用 5057、6067 两折整种子留出重拟合，校准最终选中动作相对 GP 的误差 Q90。标定值先写入文件，再用原冻结完整模型在历史种子 8171 上评价原始成本收益和错误放行。

输入与权重定义见 `protocol.json`，缓存来源见 `input_inventory.json`。8171 仅用于本轮历史开发验证；它不是新确认样本。OOF 上应用同批残差拟合的门槛属于校准表现。标签是 60 秒、PP 延续的每车道系统负荷，不能替代一小时等待或碰撞结果。

原始缓存和模型均留在服务器，额外 96 个 NPZ 仅在服务器间传输。局部静态拓扑修复在内存中进行，并要求原始特征和标签完全不变。结果写入 `result.json`；无收益则停止扩大闭环，有收益也须先通过新的多种子验证。

本轮已完成，任务 `t213670`，结论为 **HOLD_NO_EFFECT**。911 个 OOF 组中的 683 个合格建议得到 Q90=0.906156，固定 β 后惩罚为 0.453078。8171 上最大的归一化预测收益仅 0.273760；新旧门槛在 457 组中均放行 0 次、净收益为 0，放行错误率因无放行而不可估计。

原始模型的 343 个不同于 GP 的建议中，162 个改善、118 个变差、63 个持平；不设门槛时错误建议比例为 34.40%，全组等场景平均原始成本仅改善约 0.00516%。单独改变误差统计对象尚不足以形成有用干预，本轮候选停止扩大闭环。下一阶段优先级见当前研究方向，去源归因不再是默认紧接步骤。首个任务因冻结接口差异在拟合前退出，其记录保留在 `attempt1_failure.json`。
