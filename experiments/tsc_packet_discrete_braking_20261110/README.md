原578条上界偏差在四个种子分别恢复157／150／140／131条，无新增超界。3个进入候选的实际重解均值为4.28906／4.38452／4.42777米/秒，均达到入口并恢复风险许可。[固定15例的新响应](fixed15_readout.json)

似然分解解释了为何全量分数仍变差：原578条运动记录的负对数似然总和减少53.15，其余39422条增加392.48；启动正例975条减少92.01，零标签39025条增加367.42。换道已支持的439个正例分数不变，仍有9个零似然；实际保持车道的39552条损失增加463.88，其中新增换道风险的881条贡献457.60。许可扩大后，零系数模型分给未发生动作的概率也增加了。[同群分解](loss_decomposition.json)

局限：这里是目标城训练记录上的结构诊断，未证明控制或跨城收益。新增22个零标签进入许可不等于22次误操作；换道风险新增881、收回24条也只是许可变化。原9个换道正例仍使当前零参数四头目标为无穷；各自筛选后的NLL不能当同群改善。580秒例仍是目的道路一致、物理连接不同，恢复标签支持不等于复现原生物理路径。旧拟合HOLD、一般参数下联合目标及梯度未实现的状态保持。
