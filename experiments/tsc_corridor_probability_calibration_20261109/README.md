杭州坏事件中的来源权重约79%；主导状态格为当前直行、历史ETA约1–3秒、过去10秒推进速度为限速的50%–90%，部分格的来源权重达81%–91%。例如ETA第1秒格、释放时下游检测区无停车队列的有效查询，T平均概率0.688，S降至0.475，实际频率0.769；来源经验概率仅0.435。本地该格已有约287个训练快照，来源约1644个快照，直接合并使来源占约84%。

同一动作对的预测偏移还可拆成P−T与S−P，P为保持物理分层的置换来源。杭州坏事件的偏移约75.0%在P下也存在，真实条件对应另贡献25.0%；济南则约99.6%在P下也存在。因此济南主要问题是来源共同分布的迁入，杭州还存在真实条件对应带来的额外偏差。这些比例是预测分差的代数分解，不是实际损失的因果占比。

**判断与下一步。** 当前粗状态格不足以保证来源CDF适用于目标城；来源权重由样本量形成，尚未反映跨城可靠性。接下来应固定这些状态格和查询时段，利用已有的决策前相位、队列信息分层比较来源、本地训练与开发记录，检查是否遗漏了关键状态，再决定是否修改模型。

后续已完成：[当前相位与队列分层](../tsc_corridor_state_stratification_20261109/README.md)。状态组成解释部分差异，但共同支持内仍有较大跨城残差，未拟合新模型。
