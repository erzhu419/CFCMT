配对只用当前道路上的单次相邻车道变更。保持样本与正例同种子、原车道、拟比较方向、信号、停驶状态、局部车辆数档和当前邻道间隙类别，速度差≤2 m/s，距车道末端差≤15 m。每辆车最多使用一次，先配可选保持样本少的正例。904实际匹配的两项差值中位数为0.45 m/s、5.08 m。静态匹配用于选出可比案例，实际方向概率仍需读出。

当前拟合96条换道记录只有1左、2右，904的32条内部开发记录全为保持车道。若在904的1万条记录中均匀抽32条，抽不到正例的概率约68.6%。覆盖缺口来自开发抽样规模，档案已有相应事件。

四条轨迹共7200秒均参与冻结先验。448个正例中，439个已进入早期时点修正拟合，其余9个进入旧难例研究。904的62对支持当前粒子系数的内部留出诊断，结论限于这条轨迹和配对样本。配对的类别比例由设计决定，发生率校准需按原抽样分布评估。
