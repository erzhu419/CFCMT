# 换道低概率的四格分解

**类别打分抑制和前缀重加权两种影响都存在，而且不同难例的主导因素不同。** 全部138条面板引用、148次粒子规模读出完成；原始／拟合端点、类别归一化和许可质量核对均通过，未改变参数或物理掩码。[结果](result.json)

下表是9个预选真实换道正例在1024粒子下的平均NLL，越低越好；四格仅为诊断，不是四个新候选策略。

| 前缀权重 | 原始类别概率 | 拟合类别概率 |
|---|---:|---:|
| 原始权重 | 2.4732 | 5.9989 |
| 拟合权重 | 6.0061 | 9.7333 |

- **377左换道主要受类别打分抑制。** 允许该方向的前缀合计权重仅从19.04%降至16.68%，但许可条件下的拟合左换道分数约−7.98。当前线性打分中，前车净间距、左后车间距、距停止线距离等负项叠加；仅换类别概率就使NLL从2.352升至9.649。
- **1477右换道主要受前缀重加权影响。** 允许右换道的既有前缀合计权重从23.63%降至0.00594%；用同一组拟合参数、不同前缀权重加权时，许可条件下右换道平均分数从−1.785升至−0.575。仅换权重就使NLL从2.136升至10.425。
- **728左换道两者叠加。** 许可权重从5.273%降至0.01398%，许可条件下分数约−9.67；接收空间、距停止线距离、左后车间距的贡献分别约−4.79、−2.99、−2.02。四格NLL为3.636／10.180／9.568／18.548。

32个开发标签全为保持车道：仅换类别表，NLL已从0.4387降至0.0169；仅换权重为0.4423。因此该开发改善主要奖励了更强的保持车道倾向。训练的1个左换道正例分数约+0.367，2个右换道正例约+3.233／+10.102；辅助正例却出现−7.98／−9.67等分数，提示少量正例下的条件泛化不足。[分数与贡献对照](score_comparison.json)

局限：四格只解释固定缓存内的模型输出。两条NLL分解路径都闭合，但存在交互，不能分配唯一原因百分比；距离特征按固定尺度相除后仍可大于1，线性负项会继续累加。辅助例为预选难例，1178与训练重合，先验已用四轨迹7200秒，不能估计总体事件率或证明独立预测／控制收益。原200次迭代未收敛和单个运动难例退化均保留。
