# 固定15例的排除机制诊断

完成12个硬排除正例（3进入、9换道）及预先登记的3个最大运动偏差的只读复现。0新仿真、0拟合，15项测试及独立审查通过；累计仍为13次原生启动、6项拟合操作，校准数据未使用。[结果](mechanism_summary.json) · [逐案例证据](result.json)

**发现了值得修正的时间离散不一致。** 原提议用连续停距 (v^2/(2b))，推进则用1秒内的新速度。保持全部车辆参数，只把制动距离改成 (D(v,b)=\sum_{n\ge1}\max(v-nb,0))，解 (\tau v+D(v,b)=\max(g,0)+D(v_L,b_L))，得到以下代数对照：

| 种子末位／时刻／车辆末位 | 原提议上界 | 离散提议上界 | 原生下一秒速度 |
| --- | ---: | ---: | ---: |
| 901／1005／1767 | 8.74215 | 10.24461 | 10.22648 |
| 901／1396／2318 | 9.16226 | 10.66324 | 10.63431 |
| 904／1199／2072 | 8.95474 | 10.45176 | 10.42670 |

单位m/s，完整种子见JSON。3个进入正例各唯一的当前合法`g`候选也都绑定于连续跟驰项，距入口分别差0.08937、0.30681、0.03991米，原接收与空间限位均足够。离散代数提议分别为4.28906、4.38452、4.42777米/秒，均能越过入口。[六例原参数与对照](braking_comparison.json)

这项公式有独立实现依据：[SUMO1.22 Euler停距与逆](https://github.com/eclipse-sumo/sumo/blob/v1_22_0/src/microsim/cfmodels/MSCFModel.cpp#L68-L87)。[默认设置](https://github.com/eclipse-sumo/sumo/blob/v1_22_0/src/microsim/MSFrame.cpp#L316-L320)与[冻结输入及启动器](runtime_braking_evidence.json)支持本轮使用1秒Euler／Krauss的推断；六例实测自身和前车均为b=4.5、tau=1。上表只比较制动提议，未复制原生后续随机减速等处理。

**9例换道有三种不同机制。** 5例后车留在原车道，但实际比模型慢4.82–5.49m/s；2例阻挡前车同秒换离目标车道；另2例邻车误差仅0.13／0.28米，主要是本车推进高估2.94／3.94米。不能用放松一个纵向上限统一解决这些问题。

局限：尚未用离散公式重解均值、ETA或风险mask，不能宣称修复了3个硬排除；580秒案例的物理连接与原生不同、目的道路一致；期末间隙不能确定秒内换道先后。选定3个极端运动案例不能代表全部578条。一般参数下的联合目标与梯度仍未实现，旧优化器仍不兼容。
