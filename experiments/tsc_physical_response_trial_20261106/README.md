协议在新采集与拟合前冻结于[protocol.json](protocol.json)。Cologne 4种子×2状态、济南10种子×2状态，每状态8个原生动作分支，上限224条轨迹；只观察前10秒的真实进入/接收响应，450秒成本留在服务器供后续条件阶段使用。

37个输入字段全部来自动作前状态与名义信号计划。实际信号、未来路线、响应和成本不进入输入。解析接收时延使用内部车道总长度除以movement link数的距离代理。三个固定模型为目标自身、真实源、源动作置换；五折按完整目标种子留出，共30次拟合，与固定解析规则比较。主指标是非PP动作相对PP的响应差值MAE，先平均每组的动作、转向和两个输出，再按状态和种子等权汇总。

门槛：真实源减去三个对照的整种子配对95%区间上界均小于0，且两个输出各自不差于目标自身。任一不满足即关闭此配方，不在这批状态上调参。响应通过后才准备目标网络成本读出；控制收益仍需另行验证。
