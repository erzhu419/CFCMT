# 五拟合失败后的判断

**建议暂停当前信控“来源带来控制收益”的新增实验。** 若重启，需另立能递推完整网络状态、执行器相位及PP反馈的多步价值模型；现有证据不支持再追加同类成本头小修。本轮0拟合、0新仿真。

复核没有发现拟合或接线错误。确有一个RMS尺度问题：训练仅5/112行非零的rhoM_min列，被留出输入放大到155倍，单列贡献−0.3858。但五折实际成本差都为正；12次有害选择中9次的输入全部落在训练列范围内，异常不足以解释整体失败。[诊断](readout_audit_result.json)

需收窄此前“高维小样本”的解释：211列中105列为零，训练设计秩43、Ridge有效自由度约17。更直接的证据是训练排序63.54%、留出45.63%，以及成本关系未能外推。

已有反例中，动作前60秒改善75停车车辆秒，随后390秒增加2387，长期收益反转。现有分支记录有全网稀疏端点，但缺10秒后的密集车道状态与连接流；当前四维局部输出也不能递推车辆空间分布、内部库存和完整执行器状态，不能直接作为450秒闭环模型。

**下一步建议。** 收束当前配方与负结果，保留V93完整系统证据。后续若投入方法重构，应先把可递推网络状态、物理流动、执行器反馈及价值目标设计为一个完整模型，并先验证纯目标控制能力，再检验来源是否减少目标数据需求。[价值等价原理](https://arxiv.org/abs/2011.03506)支持关注模型对规划的用途；[价值感知损失的校准研究](https://arxiv.org/abs/2505.22772)也说明仅改成价值损失仍需验证。

这些文献不证明本项目的新方案有效。单未来的事后最优动作也尚未证明稳定条件平均收益；当前结论限于已关闭配方。本文仅提出研究判断，未批准或启动新模型、采集或跨项目工作。[摘要](findings.json) · [执行](execution.json)
