# 相邻路口到达时间迁移实验

**HOLD_DEVELOPMENT。** 两城均能追踪已经放行的车辆，也有可改变其直行服务的合法相位。冻结的真实源预测在杭州优于纯目标，在济南劣于纯目标。两城的距离/限速外推均优于真实源。按[预登记门槛](protocol.json)结束本轮，450 秒动作分支、四臂整小时小试和独立确认均为 0。

两城各两个已用开发种子的 PP 先导完整走完 3,600 秒。在杭州 48 条受控路段上，配对到 8,854 次直行到达，观察到 1,306 个可改变可达绿灯服务的路口时刻。济南 34 条路段对应 16,390 次和 787 个时刻。另用不重叠的 40 小时采集来源训练 16 小时、本地适配 12 小时及留出开发 12 小时，共追踪 429,123 次上游放行。全部 44 小时均无身份丢失、碰撞或传送。[先导](pilot_result.json) · [采集](collection_result.json)

预测对象为当前在途车中未来 10 秒通过直行检测面的车辆数。MAE 先在共同可预测的路段与决策时刻内计算，再对六个开发种子等权，越低越好。杭州与济南分别有 80,389 和 44,486 个可评分路段时刻。请求分歧计入全体 34,560 和 25,920 个路口决策。独立去掉纯目标对来源支持范围的依赖，杭州有 0 个、济南有 78 个额外可预测决策，实际选相均改变 0 次。[逐种子结果](development_result.json)

杭州 S 对 T 的 MAE 下降 1.24%，六个种子方向一致，但置换源保留了约 97% 的下降。济南 S 对 T 的 MAE 上升 1.86%，六个种子方向也一致。两种迁移方向均通过动作分歧次数门槛。解析外推直接用车辆的当前位置与所在车道，当前学习规则仅按路段自由流尺度、进入时排队状态及已在途时长估计到达。此次实验把限制定位到传播预测；实际动作收益和小时等待差仍未测量。
